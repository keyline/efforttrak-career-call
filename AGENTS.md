# Project agent tools

Use the local tools in `.plugins/` for work in this project. Their Codex skills are linked from `.agents/skills/`.

- Apply Ponytail's rules in `.plugins/ponytail/AGENTS.md` to coding work in every session. Use its review and audit skills when relevant.
- Use the browser-use skill for interactive browser work. The source and skill are in `.plugins/browser-use/`.
- Use the Hallmark skill for new website or page designs. Its own instructions define when it applies to existing designs.

The plugin directories and skill links are local, ignored by Git, and must be present on each machine using these tools.
